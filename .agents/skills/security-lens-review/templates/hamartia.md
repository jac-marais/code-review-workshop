# Hamartia Self-Check (Anti-Overreach Guard)

Apply after each lens completes, before synthesis.

If any lens produces >7 findings on <300 lines of reviewed code, ask:

- Cynic: "Am I subtracting or demolishing?"
- Skeptic: "Am I calibrating or paralyzing?"
- Nyaya: "Am I auditing or obstructing?"
- Confucian: "Am I correcting or pedanting?"
- Stoic: "Am I rehearsing failure or catastrophizing?"

If over-extending, keep only the top 3-4 findings and record in the review README which findings were trimmed and why.

If no lens over-produced, record one line in the README stating the check ran and no trimming was needed.
